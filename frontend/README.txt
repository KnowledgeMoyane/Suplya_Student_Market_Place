Special Command Lines:
1. npm run dev -- "Starts the development server."
2. npm run lint -- "Checks your code for problems."
3. npm run lint:fix -- "Automatically fixes problems ESLint can fix."
5. npm run format -- "Formats the entire project using Prettier."
6. npm run format:check -- "Checks whether the project is properly formatted."
7. npm run build -- "Checks TypeScript and creates the production build."
